# 06 Validate Multi-Shift and summarize import effort

[Parent specification](../spec.md)

## What to build

Use the Imported Character in team play and publish the measured effort from the first import with a separate estimate for a second fighter.

## Blocked by

[05 Validate the Imported Character moveset in team play](05-validate-imported-moveset.md)

## Acceptance criteria

- [ ] Replay a team segment that switches the Imported Character in, out and back in. Verify the active slot, health, meter, expected entry attack and continuation of the fight.
- [ ] Replay the original KOF 2003 control to check existing behavior and record how to reproduce the import tests.
- [ ] Report measured reusable tooling work and fighter-specific manual work, including blockers. Document what a second fighter could reuse as an estimate with assumptions and unknowns.

## Português (Brasil)

Usar o personagem importado em equipe e publicar o esforço medido na primeira importação, com uma estimativa separada para um segundo lutador.

### Bloqueios

[05 Validate the Imported Character moveset in team play](05-validate-imported-moveset.md)

### Critérios de aceitação

- [ ] Repetir um trecho em equipe que ponha o importado na luta, o retire e o traga de volta. Conferir a posição ativa, vida, barra, golpe de entrada esperado e continuidade da luta.
- [ ] Repetir o controle original do KOF 2003 para conferir o comportamento existente e registrar como reproduzir os testes do importado.
- [ ] Registrar o trabalho medido em ferramentas reaproveitáveis e adaptações manuais do lutador, incluindo bloqueios. Estimar o que um segundo lutador poderia reaproveitar, com hipóteses e dúvidas em aberto.
